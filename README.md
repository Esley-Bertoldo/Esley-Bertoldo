Sou estudante do 2º período de Ciência da Computação na UNINASSAU, com foco em desenvolvimento back-end utilizando Java e Spring Boot.

Possuo experiência prática em projetos acadêmicos e pessoais, envolvendo desenvolvimento de aplicações, APIs REST, bancos de dados relacionais e não relacionais e programação orientada a objetos.
